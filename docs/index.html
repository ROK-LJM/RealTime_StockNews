➕ 추적 종목 추가/삭제하는 법
위의 ✏️ 종목 편집 버튼 → 종목명·코드·티커로 검색해 추가하거나 ✕로 삭제 → 저장. 1~2분 뒤 자동 반영됩니다(최대 40개). 직접 고치려면 저장소의 config/watchlist.json 파일을 깃허브에서 편집해도 됩니다. 예: 
{
  "items": [
    { "code": "005930", "market": "KR", "name": "삼성전자" },
    { "code": "AAPL",   "market": "US", "name": "Apple" }
  ]
}
한국 종목은 6자리 코드(005930), 미국은 티커(AAPL). 저장하면 5분 안에 자동 반영됩니다.
시세: 네이버 금융·Yahoo Finance(비공식) · 뉴스: Google 뉴스 · AI 요약: Google Gemini · GitHub Actions가 약 5분마다 갱신 · 매매/주문 기능 없음
ℹ️ 시세·뉴스는 비공식 공개 데이터로, 개인 모니터링 용도로만 사용합니다.
⚠️ 예측선(점선·밴드)은 과거 60거래일 추세·변동성으로 계산한 단순 통계 추정, AI 분석은 추정일 뿐이며 실제와 다를 수 있고 투자 조언이 아닙니다.

⚡ 이 기기에서 버튼 한 번으로 저장하기 (선택)

토큰이 없으면 저장할 때 깃허브 창이 열리고, 거기서 Create를 한 번 더 눌러야 해요(깃허브 로그인 필요). 아래처럼 이슈 쓰기 권한만 있는 토큰을 이 기기에 넣어 두면 저장 버튼 한 번으로 끝납니다.

  1. 깃허브 토큰 만들기 열기(깃허브 로그인)
  2. Token name: 아무 이름 · Expiration: 원하는 기간(예: 90일)
  3. Repository access: Only select repositories → RealTime_StockNews
  4. Permissions → Repository permissions → Issues: Read and write (다른 권한은 그대로)
  5. Generate token → 복사해서 아래에 붙여넣기

토큰은 이 브라우저에만 저장되고 깃허브(api.github.com) 말고는 보내지 않아요. 이슈 쓰기 권한뿐이라 코드나 비밀키는 바꿀 수 없어요. 공용 PC에는 저장하지 마세요.
